# Glass UI (Angular + Tailwind v4)

Restrained glass: white translucent surfaces over a soft gradient with colored blurred blobs, rounded-2xl/3xl corners, bold small text, one primary color. Everything is Tailwind utilities + a handful of global classes. No UI library.

## Setup (new project)

1. Tailwind v4 via PostCSS. `.postcssrc.json` **must** enable `optimize`, or production drops nested `:hover`/`:disabled` rules generated by `@apply`:
   ```json
   { "plugins": { "@tailwindcss/postcss": { "optimize": { "minify": false } } } }
   ```
2. Copy [glass.css](glass.css) into `src/styles.css`. Change the `@theme` colors to the brand (`primary`, `secondary`, `tertiary`, `neutral`); keep the names, every recipe below relies on them.
3. Load the font (Inter) in `index.html`.
4. `@angular/cdk` for dialogs (and drag-drop if needed).

## Rules

- Use the global classes (`.btn*`, `.field-*`, `.data-table`, `.chip`, `.glass-*`) before writing long utility strings. If a pattern repeats 2+ times, add a class to `@layer components` in `styles.css` — not a per-component `.scss`.
- Surfaces: `glass-panel` (page containers, tabs, sidebars) → `glass-card` (items on a panel, hover lift) → `glass-modal` (dialogs). Don't stack glass on glass more than 2 levels; inner items use `bg-white/50`–`bg-white/90`.
- Radius: `rounded-3xl` panels/modals, `rounded-2xl` buttons/inputs/rows, `rounded-xl` small buttons/icons, `rounded-full` chips.
- Text: titles `font-extrabold text-gray-900`, body `font-medium text-gray-700`, secondary `text-gray-500`, labels `text-xs font-bold tracking-wide text-gray-500`.
- Color: `primary` for the single main action and active state; soft tones (`bg-x/10 text-x`) for status; red only for destructive/error.
- Icons: inline stroke SVG via `<app-ui-icon name>` (24×24, `currentColor`, stroke 1.9). Size with `h-4 w-4` / `h-[18px] w-[18px]`.
- Active state pattern (nav, tabs, selected options): `bg-white/90 text-primary shadow-md`; inactive `text-gray-500 hover:bg-white/60`.
- Every interactive element: `type="button"` (unless submit), `cursor-pointer`, `aria-label` on icon-only buttons, `disabled:` state.

```html
<div class="relative flex h-screen overflow-hidden bg-gradient-to-b from-[#eef2f7] via-[#f5f7fa] to-[#eef3f6]">
  <div class="bg-blob -left-28 -top-56 h-[560px] w-[560px] bg-primary/20"></div>

  <div class="bg-blob -bottom-52 left-1/3 h-[460px] w-[460px] bg-tertiary/[0.13]"></div>
  <div class="relative z-10 flex h-full w-full min-w-0 max-w-[1680px] mx-auto">
    <app-sidebar-nav class="glass-panel ..." />
    <main class="flex min-h-0 flex-1 flex-col overflow-hidden px-8 pb-8"><router-outlet /></main>
  </div>

```
Glass only reads as glass with something colorful behind it — never put `glass-*` on a flat white page.

## Recipes

### Buttons
```html
<button type="button" class="btn btn-primary"><app-ui-icon name="plus" class="h-4 w-4" [strokeWidth]="2.4" /> New</button>
<button type="button" class="btn btn-secondary">Cancel</button>
<button type="button" class="btn btn-danger">Delete</button>
<button type="button" class="btn btn-ghost">More</button>
<button type="button" class="btn btn-secondary btn-sm">Retry</button>
<button type="button" class="btn-icon" aria-label="Edit"><app-ui-icon name="edit" class="h-4 w-4" /></button>
<button type="button" class="btn-icon hover:!text-red-600" aria-label="Deactivate"><app-ui-icon name="block" class="h-4 w-4" /></button>
```
One `btn-primary` per view region. Dynamic variant: `class="btn" [class]="danger ? 'btn-danger' : 'btn-primary'"`.

### Form fields
```html
<div>
  <label class="field-label" for="email">Email</label>
  <input id="email" type="email" class="field-input" formControlName="email" />
  @if (errorOf('email'); as message) {
    <p class="field-error">{{ message }}</p>
  }
</div>
```
`.field-input.ng-invalid.ng-touched` turns red automatically. Group with `space-y-4`; side by side with `grid gap-4 sm:grid-cols-2`. Form-level error: `<p class="rounded-2xl bg-red-50 px-4 py-3 text-sm font-medium text-red-700">`.

Checkbox: `<input type="checkbox" class="h-4 w-4 accent-primary" />` inside `<label class="flex cursor-pointer items-center gap-2 text-sm font-semibold text-gray-600">`.

### Select / dropdown
Default: **native `<select>` with `field-input`** — accessible, keyboard and mobile-friendly for free.
```html
<select id="specialty" class="field-input" formControlName="specialtyId">
  <option [ngValue]="null" disabled>Select a specialty</option>
  @for (s of specialties(); track s.id) {
    <option [ngValue]="s.id">{{ s.name }}</option>
  }
</select>
```
Only build a custom dropdown when you need search or rich options. Then use `@angular/cdk/overlay` (`cdkConnectedOverlay`) or the pattern below, styled glass:
```html
<button type="button" class="field-input flex items-center justify-between text-left" (click)="open.set(!open())" [attr.aria-expanded]="open()">
  <span [class.text-gray-400]="!selected()">{{ selected()?.label ?? placeholder() }}</span>
  <app-ui-icon name="chevronDown" class="h-4 w-4 text-gray-400 transition-transform" [class.rotate-180]="open()" />
</button>
@if (open()) {
  <div class="fixed inset-0 z-10" (click)="open.set(false)"></div>
  <div class="glass-modal absolute z-20 mt-1.5 w-full overflow-hidden rounded-2xl p-1.5">
    <div class="max-h-60 overflow-y-auto">
      @for (item of items(); track item.value) {
        <button type="button" class="w-full rounded-xl px-3 py-2 text-left text-sm font-medium text-gray-700 hover:bg-white/80"
          [class]="item === selected() ? 'bg-white/90 text-primary' : ''" (click)="choose(item)">{{ item.label }}</button>
      }
    </div>
  </div>
}
```
Implement `ControlValueAccessor` if it must work with `formControlName`.

Choice cards (2–4 options, instead of a select):
```html
<label class="flex cursor-pointer items-center justify-center rounded-2xl border-2 py-2.5 text-sm font-bold transition-colors"
  [class]="value === opt.id ? 'border-primary bg-white text-primary' : 'border-transparent bg-white/50 text-gray-600'">
  <input type="radio" class="sr-only" formControlName="roleId" [value]="opt.id" /> {{ opt.label }}
</label>
```

### Table page (list + states + pagination)
```html
<app-page-header title="Staff" subtitle="Doctors and assistants">
  <button type="button" class="btn btn-primary" (click)="openForm()">New</button>
</app-page-header>

<div class="glass-panel flex min-h-0 flex-1 flex-col rounded-3xl p-4">
  <div class="min-h-0 flex-1 overflow-auto">
    @if (isLoading() && !rows().length) {
      <div class="space-y-2 p-2">
        @for (i of [1, 2, 3, 4]; track i) { <div class="h-14 animate-pulse rounded-2xl bg-white/50"></div> }
      </div>
    } @else if (errorMessage()) {
      <app-empty-state icon="alert" [title]="errorMessage()">
        <button type="button" class="btn btn-secondary btn-sm" (click)="reload()">Retry</button>
      </app-empty-state>
    } @else if (!rows().length) {
      <app-empty-state icon="staff" title="No staff yet" message="Create the first one to get started." />
    } @else {
      <table class="data-table">
        <thead><tr><th>Name</th><th>Status</th><th class="text-right">Actions</th></tr></thead>
        <tbody>
          @for (row of rows(); track row.id) {
            <tr>
              <td>
                <div class="flex items-center gap-3">
                  <span class="flex h-9 w-9 shrink-0 items-center justify-center rounded-xl bg-primary/10 text-xs font-bold text-primary">{{ initials(row.name) }}</span>
                  <div class="min-w-0">
                    <p class="truncate font-bold text-gray-900">{{ row.name }}</p>
                    <p class="truncate text-xs text-gray-500">{{ row.email }}</p>
                  </div>
                </div>
              </td>
              <td><span class="chip" [class]="row.active ? 'bg-secondary/10 text-secondary' : 'bg-gray-900/[0.06] text-gray-500'">{{ row.active ? 'Active' : 'Inactive' }}</span></td>
              <td><div class="flex justify-end gap-1"><!-- btn-icon actions --></div></td>
            </tr>
          }
        </tbody>
      </table>
    }
  </div>
  <app-pagination class="mt-3 px-2" [page]="page()" [totalPages]="totalPages()" [totalElements]="total()" (pageChange)="setPage($event)" />
</div>
```
Always cover the four states: loading skeleton, error + retry, empty, data. Headers are sticky; the panel scrolls, not the page.

### Chips / badges / status
- `.chip` + soft tone: `bg-primary/10 text-primary`, `bg-secondary/10 text-secondary`, `bg-tertiary/10 text-tertiary`, `bg-red-50 text-red-600`, neutral `bg-gray-900/[0.06] text-gray-500`.
- Status with dot: `<span class="chip" [class]="style.badge"><span class="h-1.5 w-1.5 rounded-full" [class]="style.dot"></span>{{ label }}</span>` — keep status→style/label maps in one `labels.util.ts`.
- `app-badge` component: `tone` (`primary|secondary|tertiary|neutral|danger`) × `variant` (`soft|solid`) via `Record<Tone, string>` class maps.

### Segmented tabs
Host: `glass-panel flex items-center gap-1 rounded-2xl p-1.5`. Item: `rounded-xl px-4 py-2.5 text-sm font-semibold`, active `bg-white/95 text-primary shadow-md`, inactive `text-gray-500 hover:text-gray-700`. Inputs `items`, `selectedId`; output `select`.

### Dialogs
Every dialog wraps its content in a shared `app-dialog-frame` (`glass-modal rounded-3xl p-6 max-h-[90vh]`, title `text-xl font-extrabold`, close `btn-icon`, scrollable body, footer slot). Open with the CDK and the glass backdrop:
```ts
this.dialog.open<Result, Data>(MyDialogComponent, { data, backdropClass: 'glass-backdrop' }).closed.pipe(filter(Boolean)).subscribe(...)
```
```html
<app-dialog-frame title="New member" subtitle="Doctor or assistant" (closed)="ref.close()">
  <form id="my-form" [formGroup]="form" (ngSubmit)="save()" class="space-y-4">...</form>
  <div dialogFooter class="contents">
    <button type="button" class="btn btn-secondary" (click)="ref.close()">Cancel</button>
    <button type="submit" form="my-form" class="btn btn-primary" [disabled]="saving()">Save</button>
  </div>
</app-dialog-frame>
```
The `dialogFooter` div must be a top-level child (content inside a multi-node `@if` is not projected). Confirmations go through a `ConfirmService.ask({ title, message, confirmLabel, danger })` returning `Observable<boolean>`.

### Page header, empty state, pagination
- Page header: `h1 text-[34px] font-extrabold tracking-tight text-gray-900`, subtitle `text-[15px] font-medium text-gray-500`, actions projected on the right; host `mb-7 flex flex-wrap items-center justify-between gap-4`.
- Empty state: `rounded-2xl border-2 border-dashed border-gray-900/10 px-6 py-10 text-center`, icon in `h-12 w-12 rounded-2xl bg-white/60 text-gray-400`, optional projected action.
- Pagination: zero-based `page`, hidden when `totalPages <= 1`, "Page **n** of N · X records" + two `btn-icon` chevrons.

### Sidebar nav
Items: `flex items-center gap-3 rounded-2xl px-4 py-3 text-[15px] font-semibold text-gray-500 hover:bg-white/60`, `routerLinkActive="bg-white/90 !text-primary shadow-md"`. Brand avatar: `h-10 w-10 rounded-2xl bg-primary text-white shadow-lg shadow-primary/30`. Logout: `hover:text-red-600`.

### Cards on a panel
`glass-card rounded-2xl p-4` — lifts on hover. Optional resting tilt via `--tilt`. For drag-drop, `.cdk-drag-preview` / `.cdk-drop-list-receiving` are already themed in `glass.css`.

### Toasts
Fixed `top-4 right-4 z-[60] max-w-sm`, each toast a `glass-modal rounded-2xl p-4` with a tinted icon circle (`bg-emerald-100 text-emerald-600` / `bg-red-100 text-red-600`). Driven by a root `NotificationService` with signals and auto-dismiss.

## Checklist before finishing a component

- Uses global classes, no new `.scss`, no hard-coded hex colors (theme tokens only).
- Loading / error / empty states handled.
- Icon-only buttons have `aria-label`; inputs have `<label for>`.
- Looks right over the blob background (not on plain white).
